今日のこのセッションでの、私のClaude Codeの使い方を振り返ってください。

1. この会話の流れを見て、次の観点で事実を拾う
   - **Q（品質）**：計画してから実装したか、テストやレビューを挟んだか、変更は小さかったか
   - **C（コスト）**：指示の出し直しや手戻りはあったか、/clear や /compact を使うべき切れ目はあったか、同じ指示を繰り返していないか
   - **D（スピード）**：並列化、バックグラウンド実行、コマンドやスキルにできた定型作業はあったか
2. 良かった点を1つ
3. 改善点を**3つ以内**。各項目は「いつ・何を・どう変えるか」を1〜2行で、明日すぐ試せる形にする
4. 仕事（車載ソフト開発）に持ち帰れるものがあれば1つ。会社のセキュリティ規程や機密コードの扱いに注意が必要な場合は一言添える

/context と /usage の結果があると正確になるので、未実行なら実行を勧めてください。一般論ではなく、今日の会話に基づいて指摘すること。
