---

現在の変更とリポジトリ全体のセキュリティ確認を行ってください。対象は自分のリポジトリのみです。

1. **秘密情報の混入**
   - `git ls-files` で、追跡すべきでないファイル（.env、*.pem、*.key、*.jks、トークン、認証情報）がないか
   - 追跡中のファイルに、鍵やトークンらしい文字列（AKIA…、`-----BEGIN`、token=、password= など）がないか検索する
   - .gitignore と .claude/settings.json の deny に漏れがないか
2. **子どものデータの混入**
   - 画像・音声ファイルが追跡されていないか（自作SVGと合成音以外）。実名らしい記述がないか
   - data/ などの保存フォルダが除外されているか
3. **危険なコード**
   - フロント：innerHTML、eval、外部URLへの fetch、外部CDNの読み込み、CSPの抜け
   - バックエンド：入力検証の抜け、ファイルアップロードの制限、公開環境でアップロードAPIが有効になる経路
   - インフラ：Dockerfileのrootユーザー、GitHub Actionsの過剰な permissions、OIDC信頼ポリシーの範囲、セキュリティグループ
4. **依存関係**
   - 導入済みなら `npm audit`、`uv run pip-audit`、Trivy の結果を確認する（未導入の日は「未導入」と報告する）
5. docs/security/threat-model.md の対策一覧と照らし、**実施済み／未実施／新たに見つかった脅威**を表にする

報告は「重大度（高・中・低）／場所（ファイル:行）／内容／対処案」の表にまとめ、必要なら docs/security/ に記録する案を示してください。
deny設定で読めないファイルは、読もうとせず「読めないので未確認」と報告すること。修正は私の確認後に行うこと。
