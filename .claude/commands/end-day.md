description: 今日の作業をまとめ、学習ログとplaybookに追記する
---

1日の学習を終えます。次の手順で進めてください。

1. `git log --since=midnight --oneline` と `git status`、この会話の内容から、今日の作業を把握する
2. docs/learning-log.md に、テンプレートに沿って今日の記録を追記する
   - やったこと／学んだこと3行／つまずいたこと／Claude Code活用メモ（QCD）／次にやること
   - 「学んだこと3行」は下書きを示し、私の言葉で直せるように確認を取る
3. docs/claude-code-playbook.md に、今日のClaude Code機能の行を追記・更新する（何ができるか、QCDへの効果、このプロジェクトでの使用例、仕事での使いどころ、注意点）
4. docs/plan.md の今日の完了条件と照らし、進捗を「計画どおり／遅れ（何が、どれくらい）」で示す
5. 遅れていれば、削る候補を提案して確認を取る（学習の目的は削らない）
6. 明日の予定（ゴールと最初の作業）を3行で示す
7. コミットしていない変更があれば知らせる（コミットは /commit で行う）

追記するファイルに、子どもの実名・写真・絵・録音、秘密情報、個人を特定できる情報を書かないこと。
