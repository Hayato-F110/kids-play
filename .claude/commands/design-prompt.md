Claude Designに出す依頼文を作成してください。対象：$ARGUMENTS

Claude Designは、独立サイト（claude.ai/design、2026-12-14に終了）ではなく、Claude Codeの会話内で使う（Artifactの「Design」「Design System」）。

1. docs/design.md を読み、デザインのルール、色とフォントの方針、決定済みのデザインシステムを把握する
2. 対象の画面の仕様を docs/plan.md、docs/design.md、既存の実装（あれば）から把握する。不足があれば私に質問する
3. Claude Designの機能は更新が速いので、作り方や書き出し形式に触れる場合は、公式情報で最新の使い方を確認する
4. 依頼文を作成する。次を含める
   - 目的と対象ユーザー（4〜8歳、文字が読めない子もいる）
   - 画面に必要な要素と状態（通常、押したとき、消音中 など）
   - 守るルール（64px以上、ひらがな最小限、トップに戻るボタン、消音ボタン、縦横対応、点数や失敗表現なし）
   - 技術的な制約（フレームワークなしのHTML/CSS/JS、SVG、外部フォントや外部画像を使わない）
   - 欲しい出力（画面の数、状態）
5. 使用量を抑えるため、1つの依頼の目的は1つに絞る
6. 作成した依頼文を docs/design-prompts.md に日付つきで追記する
7. 依頼文を私に見せ、確認を取ってから同じ会話で実行する（Artifactはclaude.aiに作られる。既定は非公開）

子どもの実名や写真を依頼文に含めないこと。
