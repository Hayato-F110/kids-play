# 車のサイバーセキュリティの規制と標準の動向（2026-11-06 時点）

21日目（KIDS-65）。仕事で「いま何が決まっていて、何がまだか」を説明するための整理。
規格の原文は有料なので、公開の要約と公式のページから整理した。**確かめられなかったことは、そう書く**。

## 一覧

| 名前 | 種類 | いまの状態 | 確かめ方 | 仕事への影響 |
|---|---|---|---|---|
| UN-R155 | 国連の規則（型式認証の条件） | 2021年発効。EU・日本などで新型車に必須。2025年1月発効の補足（Supplement 3）までは二次情報にある。**2026年に採択された改訂は確かめられなかった**（2026年9月に英国の改正の提案と、サイバーセキュリティと OTA の作業部会の会合の記録はある） | UNECE のサイトは自動取得を断った。二次情報のみ | CSMS（組織の仕組み）の監査と、車種ごとのリスク評価の証拠を出し続ける |
| UN-R156 | 国連の規則（ソフトウェア更新） | 2021年発効。SUMS（更新の管理の仕組み）と RXSWIN（型式に関わるソフトの識別）を求める。**2026年の改訂は確かめられなかった** | 同上 | 更新のたびに、型式に関わる影響の判断と記録が要る |
| ISO/SAE 21434 | 国際規格（開発の進め方） | 2021年版が有効。ISO は2021年版を「改訂する」と決め（2026-10-02 に見直しを締め切り）、**第2版は作業項目（AWI）の段階**。DIS（国際規格の案）はまだない。第2版の発行は 2028〜2029年ごろの見込みという業界の発表がある。範囲と構成は変えず、ISO/SAE TR 8477（検証と妥当性確認）の内容を取り込む計画とされる | ISO のカタログ（検索の結果）、業界団体の発表資料 | 当面は2021年版で進める。第2版の案が出たら、TARA と検証の章の差分を確かめる |
| ISO/PAS 8800 | 公開仕様（AI の安全） | 2024-12-13 発行。量産車の、AI を使う安全に関わる E/E システムが対象（モペッドは除く）。機械学習が中心。AI の出力の不十分さ、系統的な誤り、ハードの故障と、車外の AI とのやりとりを扱う。車の外で AI を作る工程そのものは対象外 | 各国の規格団体の目録、SIS（スウェーデン規格協会） | ISO 26262（機能安全）・ISO 21448（SOTIF）と並べて使う。AI を使う機能の安全の論拠に、データとモデルの性質を加える |
| EU サイバーレジリエンス法（CRA） | EU の規則（デジタル製品全般） | 2024-12-10 発効。**2026-09-11 から、実際に悪用された脆弱性と重大な事故の報告義務が始まった**（市場にある製品も対象）。本体の義務は 2027-12-11 から。2026-07-27 に、欧州委員会が製造者向けの手引きを出した | 欧州委員会のページ（一次情報） | 下の「車は対象か」を参照 |

## CRA：車は対象か

- **型式認証を受ける車（規則 2019/2144 の対象。乗用車・トラック・トレーラー）は CRA の対象外**（CRA 第2条2項）。車のサイバーセキュリティは、型式認証（R155・R156）で守る、という整理（前文27）
- 二輪車などの L カテゴリも、委任規則 2025/1535 で対象外になった
- **解釈が分かれる点**：車に組み込まれて認証を受ける部品は対象外だが、同じものを**単体で売る場合**（後付けの機器、アプリ、診断の道具など）は CRA の対象になりうる、という見方がある。部品メーカーや、車の外の製品（充電器、スマホのアプリ、クラウドのサービス）は個別に確かめる
- 確かめられなかったこと：官報（EUR-Lex）の本文は自動取得できず、第2条の文言は二次情報で確かめた

## 3つの関係（1枚で言うと）

```
 規則（守らないと売れない）          規格（どう作るかの手引き）
 ┌─────────────────────┐           ┌──────────────────────────┐
 │ UN-R155 CSMS         │ ◀─ 証拠 ─ │ ISO/SAE 21434（TARA など）│
 │ UN-R156 SUMS         │ ◀─ 証拠 ─ │ ISO 24089（更新の作り方） │
 │ EU CRA（車の外の製品）│           │ ISO/PAS 8800（AI の安全）  │
 └─────────────────────┘           └──────────────────────────┘
```

規則が「何を満たすか」を決め、規格が「どう作れば満たせるか」を示す。認証の審査では、規格に沿った作業の記録が証拠になる。

## 確かめられなかったこと（次に調べる）

- UN-R155・R156 の 2026年の改訂の有無（UNECE の WP.29・GRVA の会合の報告書）
- CRA 第2条の官報の本文と、部品・後付けの製品の扱いの公式の解釈
- ISO 24089 と、中国の GB 44495-2024 の最新の状況
