# デザイン

「キッズあそびランド」のデザインの決まりごと。2日目にClaude Designでデザインシステムを作り、決定した値でこのファイルを更新する。

## 対象

- 4〜8歳の子ども。文字が読めない子もいる。指が小さく、狙った場所を正確に押せないことがある
- 保護者がそばにいる想定だが、子どもだけで操作が完結すること

## 子ども向けデザインのルール

| # | ルール | 確認方法 |
|---|---|---|
| 1 | 文字に頼らない。絵・アイコン・音が中心。文字はひらがなで最小限 | 文字を隠しても遊び方が分かるか |
| 2 | ボタンは最小 64px 四方。ボタン同士の間隔は 16px 以上 | 開発者ツールで実寸を測る |
| 3 | タブレットとスマホの縦横どちらでも使える | 360×640、800×1280、その横向き、PCの1366×768 で確認 |
| 4 | タッチとマウスの両方に対応（Pointer Events） | PCのマウスとAndroid実機で確認 |
| 5 | 点数、制限時間、失敗の表現なし。何をしても楽しい | 「まちがい」「ざんねん」に当たる表現がないか |
| 6 | 音量は控えめが既定。全画面に消音ボタン。急な大音量なし | 初期音量の値、消音ボタンの位置が全画面で同じか |
| 7 | 激しい点滅なし（1秒に3回を超える点滅をしない）。`prefers-reduced-motion` を尊重 | アニメーションの周期を確認 |
| 8 | 広告、外部リンク、外部への通信なし | 開発者ツールのNetworkタブで外部通信が0件 |
| 9 | どの画面からも1タップでトップに戻れる | 「おうち」ボタンが全画面の同じ位置にあるか |

## ミニアプリの仕様（2026-10-09 決定）

数は「遅れたときに削る候補」の対象。減らしても遊びが成り立つ最小数をかっこ内に示す。

### 0. トップ（メニュー）

- 4つの大きなアイコンのボタン。スマホ縦は2列×2段、横長の画面は4つ横並びまたは2列×2段
- 各ボタンの下に、ひらがなの名前を小さく添える（なくても選べること）
- 右上に消音ボタン。おうちボタンは置かない（ここがトップなので）
- まだ作っていないミニアプリのボタンも並べ、押すと「じゅんびちゅう」の絵を出す（失敗の表現にしない）

### 1. どうぶつタッチ

- 動物は6種（最小3種）：いぬ、ねこ、うし、ひよこ、かえる、ひつじ。合成音で鳴き声を作りやすいものを選んだ
- タップすると、その動物が動き（はねる、ゆれる など）、鳴き声が鳴る。連打しても音が重なりすぎない
- 遊び方の説明、正解、順番はない。どれをいつ押してもよい

### 2. おとあそびピアノ

- 鍵盤は8つ（ド〜高いド）。1つずつ色が違い、押している間だけ光って音が鳴る
- 同時押しができる（マルチタッチ）。指をすべらせると次の鍵盤が鳴る
- 曲の手本、採点はない

### 3. おえかきスタンプ

- 色6色（最小4色）、太さ3段階、スタンプ4種（最小2種：ほし、はな、はーと、おひさま）
- 「ぜんぶけす」は、押し間違えても困らないように、1回目で確認の絵を出し2回目で消す
- 「ほぞん」はPNGを端末にダウンロードするだけ。どこにも送信しない

### 4. わたしのえほん

- 1冊8ページまで。各ページは、絵1枚（おえかきと同じ道具で描く）と録音1つ（最長30秒）
- 「よむ」を押すと、1ページ目から順に絵を出し、録音を再生する（紙芝居）
- ページの削除と、全データの削除ができる（保護者向け。長押しで実行）
- 絵と録音は端末内（IndexedDB）にのみ保存する。マイクの許可は、録音ボタンを初めて押したときに求める

## 色とデザイントークン（2日目に仮決定。子どもの反応を見て3日目に確定）

- 明るく、やわらかい色。原色のベタ塗りより、少し白を混ぜた色
- 押せる部品には、必ず `--color-text` の太い輪郭線を付ける。アクセント色は背景との明るさの差が小さいので、輪郭線で 3:1 以上を確保する
- 色だけで意味を伝えない（形やアイコンも変える）
- CSSカスタムプロパティ（デザイントークン）で定義する。値の元はデザインシステム（下の「Claude Designのプロトタイプ」のリンク）

| トークン | 用途 | 値 |
|---|---|---|
| `--color-bg` | 背景 | `#e8f4fb` |
| `--color-surface` | アイコンの中の白い面、消音中のボタン、キャンバス | `#ffffff` |
| `--color-text` | 文字と、すべての輪郭線 | `#23324a` |
| `--color-text-soft` | 補足の小さな文字 | `#4d5d78` |
| `--color-primary` | 共通ボタン（おうち、消音）、フォーカスの枠 | `#2c63c4` |
| `--color-on-primary` | `--color-primary` の上のアイコン | `#ffffff` |
| `--color-accent-1` | どうぶつタッチ | `#ffb23e` |
| `--color-accent-2` | おとあそびピアノ | `#f2708f` |
| `--color-accent-3` | おえかきスタンプ | `#4fbf8b` |
| `--color-accent-4` | わたしのえほん | `#8f7be8` |
| `--space-1` 〜 `-4` | 余白 | `8px` `16px` `24px` `32px` |
| `--radius-sm` `-md` `-lg` | 角の丸み（小さな部品／鍵盤など／メニューボタン） | `12px` `24px` `40px` |
| `--tap-min` | 最小タップ領域 | `64px` |
| `--stroke` | 輪郭線の太さ | `4px` |
| `--pop` | 押したときに沈む深さ | `6px` |
| `--shadow-pop` | 押せる部品の下の段（ぼかさない） | `0 6px 0 #23324a` |

実装では、大きさと余白を `rem` と `clamp()` に置き換える（16px = 1rem）。

文字の大きさは3段階：`label-lg` 32px（タイトル）、`label-md` 24px（ボタンの名前）、`label-sm` 20px（最小）。太さはすべて 700。

押している間は、部品を `--pop` の分だけ下げて `--shadow-pop` を消す。フォーカスの枠は `--color-primary` の実線4px。

## フォントの方針

- 外部フォントは読み込まない（外部通信なしのルール）。端末の丸ゴシック系を優先するフォントスタックを使う
- 文字はひらがな。大きさは `clamp()` で画面に合わせ、最小でも 20px 相当
- 文字数は1つのボタンにつき6文字程度まで

## アイコンとイラストの作風（2日目に仮決定）

- 自作SVG。太めの線、丸い形、単純な図形の組み合わせ
- 動物は 200×200 の viewBox に顔だけを大きく描く。線は `--color-text` の6px、先と角は丸くする
- 塗りはデザイントークンの色だけを使う。ほっぺと耳の内側は `--color-accent-2`
- 顔のある絵は、やさしい表情にする（目は丸、口は上向きの曲線）
- 3日目にスキル化し、同じ作風で量産できるようにする

## 音量の方針

- マスター音量の初期値は控えめ（Web AudioのGainで 0.2〜0.3 を目安に、実機で決める）
- 音の立ち上がりと終わりをなめらかにする（急なクリック音を出さない）
- 同時に鳴る音の数に上限を設け、合計の音量が大きくなりすぎないようにする
- 消音の状態は端末内に保存し、画面を移動しても維持する
- 最初のタップまでは音を鳴らさない（ブラウザの自動再生制限にも合う）
