# デザイン

「キッズあそびランド」のデザインの決まりごと。2日目にClaude Designでデザインシステムを作り、決定した値でこのファイルを更新する。

## 対象

- 4〜8歳の子ども。文字が読めない子もいる。指が小さく、狙った場所を正確に押せないことがある
- 保護者がそばにいる想定だが、子どもだけで操作が完結すること

## 子ども向けデザインのルール

| # | ルール | 確認方法 |
|---|---|---|
| 1 | 文字に頼らない。絵・アイコン・音が中心。文字はひらがなで最小限 | 文字を隠しても遊び方が分かるか |
| 2 | ボタンは最小 64px 四方。ボタン同士の間隔は 16px 以上 | 開発者ツールで実寸を測る |
| 3 | タブレットとスマホの縦横どちらでも使える | 360×640、800×1280、その横向き、PCの1366×768 で確認 |
| 4 | タッチとマウスの両方に対応（Pointer Events） | PCのマウスとAndroid実機で確認 |
| 5 | 点数、制限時間、失敗の表現なし。何をしても楽しい | 「まちがい」「ざんねん」に当たる表現がないか |
| 6 | 音量は控えめが既定。全画面に消音ボタン。急な大音量なし | 初期音量の値、消音ボタンの位置が全画面で同じか |
| 7 | 激しい点滅なし（1秒に3回を超える点滅をしない）。`prefers-reduced-motion` を尊重 | アニメーションの周期を確認 |
| 8 | 広告、外部リンク、外部への通信なし | 開発者ツールのNetworkタブで外部通信が0件 |
| 9 | どの画面からも1タップでトップに戻れる | 「おうち」ボタンが全画面の同じ位置にあるか |

## 色の方針（仮。2日目に決定）

- 明るく、やわらかい色。原色のベタ塗りより、少し白を混ぜた色
- 背景と部品のコントラストを十分に取る（アイコンと背景で 3:1 以上を目安）
- 色だけで意味を伝えない（形やアイコンも変える）
- CSSカスタムプロパティ（デザイントークン）で定義する

| トークン | 用途 | 値 |
|---|---|---|
| `--color-bg` | 背景 | （2日目に決定） |
| `--color-primary` | 主要なボタン | |
| `--color-accent-1` 〜 `-4` | 4つのミニアプリの色 | |
| `--color-text` | 文字 | |
| `--radius` | 角の丸み | |
| `--space` | 余白の基本単位 | |
| `--tap-min` | 最小タップ領域 | `64px` |

## フォントの方針

- 外部フォントは読み込まない（外部通信なしのルール）。端末の丸ゴシック系を優先するフォントスタックを使う
- 文字はひらがな。大きさは `clamp()` で画面に合わせ、最小でも 20px 相当
- 文字数は1つのボタンにつき6文字程度まで

## アイコンとイラストの作風（仮。2日目に決定）

- 自作SVG。太めの線、丸い形、単純な図形の組み合わせ
- 顔のある絵は、やさしい表情にする
- 3日目にスキル化し、同じ作風で量産できるようにする

## 音量の方針

- マスター音量の初期値は控えめ（Web AudioのGainで 0.2〜0.3 を目安に、実機で決める）
- 音の立ち上がりと終わりをなめらかにする（急なクリック音を出さない）
- 同時に鳴る音の数に上限を設け、合計の音量が大きくなりすぎないようにする
- 消音の状態は端末内に保存し、画面を移動しても維持する
- 最初のタップまでは音を鳴らさない（ブラウザの自動再生制限にも合う）
