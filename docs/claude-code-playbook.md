# 仕事で使えるClaude Code活用ガイド（QCD別）

毎日1つ、Claude Codeの機能を実際に使い、効果と仕事での使いどころを記録する。14日目に仕上げる。

- 機能の説明は公式ドキュメント（https://code.claude.com/docs）と /release-notes に基づく
- QCD：**Q**＝品質、**C**＝コスト（トークンと手戻り）、**D**＝スピード
