# Claude Designに出す依頼文

`/design-prompt` で作成した依頼文をここに記録する。

- Claude Designは、Claude Codeの会話内で使う（Artifactの「Design」「Design System」）。独立サイト（claude.ai/design）は2026-12-14に終了するので使わない
- 使う前に、Claude Designの最新の使い方を公式情報で確認する
- 使用量を抑えるため、1回の依頼の目的は1つに絞る
- 子どもの写真や実名は入力しない

---

## 2日目-1：デザインシステム（2026-10-09 に使用予定）

```text
4〜8歳の子ども向けミニアプリ集「キッズあそびランド」のデザインシステムを作ってください。

# 対象
- 4〜8歳の子ども。文字が読めない子もいる。指が小さく、正確に押せないことがある
- 遊ぶ端末：Androidのスマホとタブレット（縦横どちらも）、Windows PCのブラウザ（マウス）

# 作ってほしいもの
1. 色：背景、主要ボタン、4つのミニアプリを区別する4色、文字色。明るくやわらかい色で、アイコンと背景のコントラストは3:1以上
2. 文字：ひらがなのみ。端末に入っている丸ゴシック系のフォントを使う（外部フォントは使わない）。大きさは3段階
3. ボタン：大きな丸みのあるボタン。通常、押している間、の2状態。最小 64px 四方、間隔 16px 以上
4. 共通の部品：「おうち」ボタン（トップに戻る）と「消音」ボタン（音あり／消音中の2状態）
5. アイコンとイラストの作風：太めの線、丸い形、単純な図形の組み合わせ。SVGで描ける単純さにする。見本として動物を2つ（いぬ、ねこ）
6. 余白と角の丸みの基準

# 守るルール
- 文字に頼らず、絵とアイコンで伝える
- 点数、時間制限、失敗（×印や赤い警告）の表現は使わない
- 激しい点滅や強すぎる色の対比は避ける
- 写真は使わない

# 技術的な制約
- 実装はフレームワークなしの HTML / CSS / JavaScript。色・余白・大きさは CSS カスタムプロパティ（例：--color-bg）で定義できる形にする
- 画像はすべて SVG

# 出力
- デザインシステムを1枚にまとめたもの（色、文字、ボタン、共通の部品、アイコンの見本）
- CSSカスタムプロパティの一覧
```

## 2日目-2：トップ画面のプロトタイプ（2026-10-09 に使用予定）

```text
先ほどのデザインシステムを使い、「キッズあそびランド」のトップ画面（メニュー）のプロトタイプを作ってください。

# 画面の内容
- 4つのミニアプリに移動する、大きなアイコンのボタンが4つ
  1. どうぶつタッチ（動物の顔）
  2. おとあそびピアノ（色とりどりの鍵盤）
  3. おえかきスタンプ（クレヨンと星のスタンプ）
  4. わたしのえほん（開いた絵本）
- 各ボタンの下に、ひらがなの名前を小さく添える
- 右上に消音ボタン
- 上部にタイトル「きっず あそびらんど」（小さめでよい）

# レイアウト
- スマホ縦（360×640）：2列×2段
- タブレット横（1280×800）とPC：4つが横に並ぶ、または2列×2段で大きく
- どの大きさでも、ボタンは 64px 四方よりずっと大きく、画面いっぱいに使う

# 状態
- 通常
- ボタンを押している間（少し沈む、または少し大きくなる）

# 守るルール
- 広告、外部リンク、設定メニュー、ログインは置かない
- 文字はひらがなのみ

# 出力
- スマホ縦とタブレット横の2種類
- HTML と CSS として書き出せる形（フレームワークなし、画像はSVG、外部フォントなし）
```

## 4日目：おえかきスタンプの画面（2026-10-11 に使用）

デザインシステム（キッズあそびランド デザインシステム）を付けて、Artifactの「Design」のキャンバスに作る。

```text
デザインシステム「キッズあそびランド デザインシステム」を使い、ミニアプリ「おえかきスタンプ」の画面のプロトタイプを作ってください。

# 目的と対象
- 4〜8歳の子どもが、指（またはマウス）で絵を描き、スタンプを押し、画像として保存する画面
- 文字が読めない子もいる。指が小さく、正確に押せないことがある

# 画面に必要な要素
- キャンバス（白。画面の中でいちばん大きくする）
- 色を選ぶボタン 6色（デザインシステムの色から選ぶ。白い紙の上ではっきり見える色にする）
- 線の太さを選ぶボタン 3段階（ほそい・ふつう・ふとい。丸の大きさで表す）
- スタンプを選ぶボタン 4種（ほし、はな、はーと、おひさま）
- 「ぜんぶけす」ボタン
- 「ほぞん」ボタン
- おうちボタン（左上）と消音ボタン（右上）。位置と大きさはデザインシステムのまま

# いちばん考えてほしいこと
- 道具のボタンは合計15個ある。スマホ縦（360×640）で、ボタン64px・間隔16pxを守ると、すべて並べるとキャンバスが小さくなる
- キャンバスを広く保てる道具の置き方を提案してほしい（例：色とスタンプを切り替えて出す、横にすべらせる など）。子どもが迷わない単純さを優先する

# 状態
1. 通常（色と太さを1つずつ選んでいる。選んでいるものが、色だけでなく形や枠でも分かる）
2. スタンプを選んでいる（ペンではなくスタンプの番だと分かる）
3. 「ぜんぶけす」を1回押した（確認の絵を出す。もう1回押すと消える。×印や赤い警告にしない）
4. 「ほぞん」を押した直後（できたことが絵で分かる。短い時間で元に戻る）

# 守るルール
- ボタンは最小 64px 四方、間隔 16px 以上
- 文字はひらがなで最小限。なくても遊べること
- 点数、制限時間、失敗の表現なし
- 広告、外部リンク、設定メニューは置かない
- 激しい点滅なし
- 写真は使わない。キャンバスの中の見本の絵は、単純な線とスタンプだけにする

# 技術的な制約
- 実装はフレームワークなしの HTML / CSS / JavaScript。色・余白・大きさはデザインシステムのCSSカスタムプロパティを使う
- 画像はすべてSVG。外部フォント、外部画像は使わない

# 出力
- スマホ縦（360×640）とタブレット横（1280×800）の2種類
- スマホ縦は状態1〜4の4枚、タブレット横は状態1の1枚（合計5枚）
```

## 7日目：わたしのえほんの画面（2026-10-14 に使用）

デザインシステム（キッズあそびランド デザインシステム）を付けて、Artifactの「Design」のキャンバスに作る。おえかきスタンプのプロトタイプ（4日目）の道具の並びを引き継ぐ。

```text
デザインシステム「キッズあそびランド デザインシステム」を使い、ミニアプリ「わたしのえほん」の画面のプロトタイプを作ってください。

# 目的と対象
- 4〜8歳の子どもが、自分で絵を描き、声を録音して、紙芝居のように再生する「えほん」を作る
- 文字が読めない子もいる。指が小さく、正確に押せないことがある
- 1冊は8ページまで。各ページは、絵1枚と録音1つ（最長30秒）

# 画面
A. ほんだな（ページの一覧）
- 8ページ分の枠。絵のあるページは小さな絵を、まだのページは「＋」の枠を出す
- 録音があるページには、それと分かる小さな印（音の波など）
- 「よむ」ボタン（大きく）
- おうちボタン（左上）と消音ボタン（右上）。位置と大きさはデザインシステムのまま

B. ページを作る
- 絵を描く部分（おえかきスタンプと同じ道具。色6つ、太さ、スタンプ。並びは、おえかきスタンプのプロトタイプと同じにする）
- 録音のボタンと、録った声を聞くボタン、録り直すボタン
- ほんだなに戻るボタン

C. よむ（紙芝居）
- 絵を画面いっぱいに出し、録音を再生する。終わると次のページへ進む
- まえ・つぎのボタン、とじるボタン

# いちばん考えてほしいこと
1. 録音の3つの操作（ろくおん、きく、とりなおす）を、文字なしで区別できる形。録音中であることが、はっきり分かる表し方（赤い丸と、動く音の波など）。30秒の上限は、残り時間の数字ではなく、だんだん満ちる輪などで表す（制限時間の表現にしない）
2. ページの削除は保護者向け（長押しで実行）。子どもが誤って消さず、保護者には分かる形。長押しの間に満ちていく輪を出し、×印や赤い警告にしない

# 状態
1. A ほんだな：3ページ分ができている（2ページは録音あり、1ページは録音なし）
2. B ページを作る：録音の前
3. B ページを作る：録音中
4. B ページを作る：録音のあと（きく、とりなおすが押せる）
5. C よむ：再生中
6. A ほんだな：ページを長押ししている途中（削除の輪が満ちていく）

# 守るルール
- ボタンは最小 64px 四方、間隔 16px 以上
- 文字はひらがなで最小限。なくても遊べること
- 点数、制限時間、失敗の表現なし
- 広告、外部リンク、設定メニューは置かない
- 激しい点滅なし（録音中の表示も、ゆっくり動かす）
- 写真は使わない。ページの見本の絵は、単純な線とスタンプだけにする

# 技術的な制約
- 実装はフレームワークなしの HTML / CSS / JavaScript。色・余白・大きさはデザインシステムのCSSカスタムプロパティを使う。この画面の色は --color-accent-4
- 画像はすべてSVG。外部フォント、外部画像は使わない

# 出力
- スマホ縦（360×640）で、状態1〜6の6枚
- タブレット横（1280×800）で、状態1と状態3の2枚（合計8枚）
```
