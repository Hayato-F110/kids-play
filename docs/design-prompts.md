# Claude Designに貼り付けるプロンプト

`/design-prompt` で作成したプロンプトをここに記録する。

- 使う前に、Claude Designの最新の使い方（Claude Codeへの引き継ぎ方法、エクスポート形式）を公式情報で確認する
- 使用量を抑えるため、1回の依頼の目的は1つに絞る
- 子どもの写真や実名は入力しない

---

## 2日目-1：デザインシステム（2026-10-09 に使用予定）

```text
4〜8歳の子ども向けミニアプリ集「キッズあそびランド」のデザインシステムを作ってください。

# 対象
- 4〜8歳の子ども。文字が読めない子もいる。指が小さく、正確に押せないことがある
- 遊ぶ端末：Androidのスマホとタブレット（縦横どちらも）、Windows PCのブラウザ（マウス）

# 作ってほしいもの
1. 色：背景、主要ボタン、4つのミニアプリを区別する4色、文字色。明るくやわらかい色で、アイコンと背景のコントラストは3:1以上
2. 文字：ひらがなのみ。端末に入っている丸ゴシック系のフォントを使う（外部フォントは使わない）。大きさは3段階
3. ボタン：大きな丸みのあるボタン。通常、押している間、の2状態。最小 64px 四方、間隔 16px 以上
4. 共通の部品：「おうち」ボタン（トップに戻る）と「消音」ボタン（音あり／消音中の2状態）
5. アイコンとイラストの作風：太めの線、丸い形、単純な図形の組み合わせ。SVGで描ける単純さにする。見本として動物を2つ（いぬ、ねこ）
6. 余白と角の丸みの基準

# 守るルール
- 文字に頼らず、絵とアイコンで伝える
- 点数、時間制限、失敗（×印や赤い警告）の表現は使わない
- 激しい点滅や強すぎる色の対比は避ける
- 写真は使わない

# 技術的な制約
- 実装はフレームワークなしの HTML / CSS / JavaScript。色・余白・大きさは CSS カスタムプロパティ（例：--color-bg）で定義できる形にする
- 画像はすべて SVG

# 出力
- デザインシステムを1枚にまとめたもの（色、文字、ボタン、共通の部品、アイコンの見本）
- CSSカスタムプロパティの一覧
```

## 2日目-2：トップ画面のプロトタイプ（2026-10-09 に使用予定）

```text
先ほどのデザインシステムを使い、「キッズあそびランド」のトップ画面（メニュー）のプロトタイプを作ってください。

# 画面の内容
- 4つのミニアプリに移動する、大きなアイコンのボタンが4つ
  1. どうぶつタッチ（動物の顔）
  2. おとあそびピアノ（色とりどりの鍵盤）
  3. おえかきスタンプ（クレヨンと星のスタンプ）
  4. わたしのえほん（開いた絵本）
- 各ボタンの下に、ひらがなの名前を小さく添える
- 右上に消音ボタン
- 上部にタイトル「きっず あそびらんど」（小さめでよい）

# レイアウト
- スマホ縦（360×640）：2列×2段
- タブレット横（1280×800）とPC：4つが横に並ぶ、または2列×2段で大きく
- どの大きさでも、ボタンは 64px 四方よりずっと大きく、画面いっぱいに使う

# 状態
- 通常
- ボタンを押している間（少し沈む、または少し大きくなる）

# 守るルール
- 広告、外部リンク、設定メニュー、ログインは置かない
- 文字はひらがなのみ

# 出力
- スマホ縦とタブレット横の2種類
- HTML と CSS として書き出せる形（フレームワークなし、画像はSVG、外部フォントなし）
```
