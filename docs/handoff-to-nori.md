- 車載ソフト開発のエンジニア（C 言語、車載 ECU、ISO/SAE 21434、TARA）。Web・3D・CI/CD・クラウドは学びながら

## 5. つまずき防止（Windows と道具）

| 事柄 | 内容 |
|---|---|
| Bash と PowerShell | 日常のコマンドは PowerShell の道具で実行する。allow は道具ごとに効くので、PowerShell を許可しても Bash で実行すると確認が出る |
| `npx` | kids-play では ask にしていたので確認が出た。`npm run <スクリプト>` を使う |
| PowerShell の `switch` | 要素が1つの配列を開いてしまう（OpenTofu に「t」だけが渡った）。`@()` で囲む |
| PowerShell の `$Matches` | 2回目の `-match` で上書きされる。破壊的なコマンドの対象に使わない（6日目の事故の原因） |
| PowerShell の `--` | 関数に渡すと PowerShell が取り除く（`kubectl exec --` が壊れた） |
| `git commit -F -` ＋ here-string | PowerShell では動かない。メッセージは一時フォルダーのファイルに書いて `-F <ファイル>` |
| 改行 | 文書は LF。PowerShell の `Add-Content` は CRLF を足すので、足したあとに LF にそろえる |
| `python -I` | 外部から取ったファイルを読むときに使う。`-I` は `PYTHONIOENCODING` も無視するので、日本語の出力は `-X utf8` を足す |
| VS Code のターミナルと `.venv` | VS Code がターミナルで `.venv` を自動で有効にし、別のプロジェクトの `pip install` が kids-play の `.venv` に入った（TensorFlow など 4.1GB、2回）。PC 全体に入れるときは `py -3.14 -m pip ...` を使う |
| `uv cache prune` が待ったまま | Claude Code の MCP サーバーが `uv run` で動いていると、キャッシュが使用中になる。VS Code を閉じて、外のターミナルで実行する。`--force` は使わない |
| ローカルの main が古い | 新しいブランチを作る前に `git pull --ff-only` |
| GitHub の障害 | push や PR の作成が続けて失敗したら、手元を疑う前に githubstatus.com を見る。間隔を広げてやり直す |
| Dependabot のアラートの一覧 | `state=open` で、直ったはずのものが出ることがあった。1件ずつ読むと `fixed` だった |
| Claude Design（Slides）の PowerPoint への書き出し | 動画は静止画になる。必要なら python-pptx で入れ直す（`add_movie`） |
| 作業フォルダーの外 | Claude のファイルの道具は、作業フォルダーの外に書けない（`blockWritesOutsideWorkingDirectories`）。kids-play から NORI のファイルは書けない |
| 長い作業の途中のログアウト | 区切りごとにコミットしておけば失わない。`claude -p` の stderr にサインインの期限の警告が出たら、早めにログインし直す |

## 8. 安全の教訓（NORI でも同じことが起きうる）

- **AI の手が届く範囲**：作業フォルダーの制限は、ファイルの道具にだけ効く。シェルのコマンドは、PC につながるものすべて（USB の端末、ネットワーク、クラウド）に届く。壊せる相手をつないでいる間は、コマンドを人が1つずつ承認する
- **画面の写し**：14日目に、家族の写真が写った画像をリポジトリに置きかけた。スクリーンショットは `.gitignore` で除外し、渡す前に壁紙・通知・タブ・アドレスバーを見る
- **秘密の値**：13日目に、DNS の token を会話に貼った。貼る前に見る。漏れたら、すぐ作り直す
- **既定の動き**：11日目に、コンテナイメージが既定で公開になった。公開範囲は、実行の前に確かめ、出したあとにも外から確かめる
- **構成を変えたら、前の対策を見直す**：11日目に、前に置いた nginx が守りを崩した
- **模擬と本物**：19日目に、テストで自分で作った値が、本物のブラウザの動き（Origin が null）と違った。最後は本物で確かめる
- **生成 AI のサービスは終わることがある**：Sora は 2026 年に終了した。作った物と来歴（C2PA）を手元に残す。Firefly の動画には目に見える透かしがなく、手がかりは C2PA だけ（保存し直すと消える）なので、公開するときは「AI で作った」と書き添える
- **開発用の部品の脆弱性**：攻撃者が入力できないことを確かめたうえで、理由と見直しの条件をつけて「受け入れたリスク」として記録した（minimatch、21日目）。黙って放置しない
